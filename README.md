# 简历制作工具（Resume Maker）

一个**单文件、零依赖**的网页版简历制作工具。双击 `index.html` 即可在浏览器中使用，数据保存在本地浏览器（localStorage），无需联网、无需安装。

## 功能特性

- **所见即所得**：左侧编辑，右侧 A4 实时预览
- **模块化编辑**：基本信息、教育背景、专业技能、项目经历、工作经历、实习经历、兴趣爱好，支持拖拽排序、自定义模块、模块显隐
- **富文本**：任意文字可加粗、调整字号、首行缩进，支持 7 种中文字体切换
- **多简历管理**：一份管理多份，可重命名、切换、删除
- **导出**：
  - 导出 PDF（整页，高度随内容自适应）
  - 分页导出（标准 A4，智能分页：页面填满、段落不截断、标题不孤立页底）
  - 导出纯文本
- **本地保存**：数据存 localStorage，刷新不丢

## 使用方法

1. 直接双击 `index.html`，用浏览器打开即可使用
2. 或部署到 GitHub Pages：仓库 `Settings → Pages`，选择 `main` 分支即可

## 技术栈

- 纯 HTML + CSS + JavaScript，单文件，无任何依赖
- PDF 导出按需加载 html2canvas + jsPDF（CDN），离线时自动回退到浏览器系统打印
